The Avalonia desktop app supports qualified Windows x64, Linux x64/X11 and macOS ARM64 packages. Download only assets published for your operating system and architecture.

No production installer is published by the initial deployment implementation. CI artifacts are unsigned or ad-hoc-signed test candidates. Stable update entries remain empty until signing and installation qualification pass and a release is explicitly authorized.
